## 💡 Sobre o Projeto

Este projeto é o meu primeiro passo no desenvolvimento web, construído como parte dos meus estudos em Ciência da Computação. O objetivo principal é demonstrar minhas habilidades iniciais em estruturação e estilização de páginas web.

O design adota um **tema azul marinho**, refletindo um visual limpo e focado no conteúdo.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as bases do desenvolvimento Front-end:

* **HTML5:** Para a estruturação e a semântica do conteúdo.
* **CSS3:** Para toda a estilização e o layout responsivo.
